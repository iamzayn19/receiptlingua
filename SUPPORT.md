# Support

- **Bugs / feature requests**: open a GitHub issue in this repository.
- **Usage questions**: open a GitHub Discussion (once enabled) or an issue
  tagged `question`.
- **Security issues**: see [SECURITY.md](SECURITY.md) — do not use public
  issues.
- **Documentation**: start with [README.md](README.md),
  [ARCHITECTURE.md](ARCHITECTURE.md), and [LANGUAGES.md](LANGUAGES.md).

This is a community-maintained open-source project with no paid support
tier. Response times are best-effort.
