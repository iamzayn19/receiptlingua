Language support matrix

Rendered live from the same language_matrix.json the Python package ships and LANGUAGES.md is generated from — this page fetches a copy of that file client-side rather than re-typing the data, so it can't silently drift into a rosier hand-written table.

Two separate, deliberately-not-conflated columns: Model-supported means the backend stack can technically produce output for this language (a py3langid label and a documented Tesseract tessdata_fast pack). Receipt-verified means there is real benchmark evidence it works well specifically on receipts. As of this writing, receipt-verified is false for every language — no receipt benchmark covers per-language accuracy yet beyond the 5 languages in Benchmarks.
