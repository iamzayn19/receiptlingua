Support

Getting help

  • Bugs / feature requests: open a GitHub issue.
  • Usage questions: a GitHub Discussion (once enabled) or an issue tagged question.
  • Security issues: see SECURITY.md — please do not use public issues for these.

This is a community-maintained open-source project with no paid support tier. Response times are best-effort.

Acknowledgements

ReceiptLingua is built on top of, and grateful to, a number of open-source projects:

  • Tesseract OCR and the tessdata_fast language packs.
  • PaddleOCR, an optional backend.
  • py3langid for offline language identification.
  • The regex package's Unicode script-property matching, used for script segmentation.
  • arabic-reshaper and python-bidi for Arabic/Hebrew shaping and bidi reordering.
  • NumPy, Pillow, and OpenCV for image processing.

Full license text for each dependency is tracked per-ecosystem (python/pyproject.toml, javascript/package.json, ruby/receiptlingua.gemspec) and in generated SBOMs (see python/scripts/generate_sbom.py).

ReceiptLingua is open source (Apache-2.0). Source on GitHub. No analytics or trackers on this site.
